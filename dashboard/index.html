Review engine

Which CLI reviews the PRs. Each runs headless and read-only inside the PR worktree. Leave the model empty to use the CLI's default.

API keys

Stored in .env in the bot folder (chmod 600, gitignored), and never sent back to this page. Leave a key empty to use that CLI's own login (claude.ai, ChatGPT or Google). Each engine only receives its own key.

Repositories

Local path is optional: leave it empty and the bot keeps its own lightweight clone. Your working copy is never checked out or modified either way. Extra rules are appended to the review prompt for that repo.
